# GYM Peg — handoff de design v2 (15/10/2026)

- `DESIGN-RULES.md` (raiz do repo): regras obrigatórias, incluindo a lista do que é proibido.
- `docs/design/tokens.css`: tokens HSL no padrão shadcn. `:root` é o claro (padrão); `.dark` é opcional.
- `docs/design/tailwind.gympeg.ts`: extensão do Tailwind (fontes, escala, cores semânticas, raios, alturas).
- `docs/design/CLAUDE_CODE_PROMPT.md`: o prompt para o Claude Code.
- `docs/design/mocks/`: telas de referência. Abra `GYM Peg v2.dc.html` com `npx serve docs/design/mocks`.
- `public/icons/`, `public/brand/mark.svg`: símbolo 1c e ícones do PWA (os mesmos da v1).
